Instruction on how to build .typ documents :

1. You will need Tinymist, a typst compiler and LSP https://github.com/Myriad-Dreamin/tinymist
2. Go to your document directory and execute the command ```$ tinymist compile <yourfile.typ>```

Compilation is done in seconds, you should now have a PDF file named after the file you compiled.

If you are using VSCode an even simpler method exists,
all you need to do is download the Tinymist extension and follow this manual : https://myriad-dreamin.github.io/tinymist/frontend/vscode.html
There is no system requirements.
